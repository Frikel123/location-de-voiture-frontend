# 🔐 AUTH (Admin)

## ➤ POST /auth/login

### Description:

Authentifie un admin et retourne un token JWT.

### Request:

```json
{
  "email": "admin@test.com",
  "password": "123456"
}
```

### Response (200):

```json
{
  "token": "JWT_TOKEN"
}
```

### Errors:

* 401 Unauthorized → email ou password incorrect

# 🚗 CARS

## ➤ GET /cars

### Description:

Retourne la liste de toutes les voitures

### Response:

```json
[
  {
    "id": 1,
    "name": "Clio 4",
    "price": 250,
    "image": "API_BASE_URL/uploads/clio.jpg"
  }
]
```

---

## ➤ GET /cars/:id

### Description:

Retourne une voiture par ID

### Response:

```json
{
  "id": 1,
  "name": "Clio 4",
  "price": 250,
  "image": "API_BASE_URL/uploads/clio.jpg"
}
```

## ➤ POST /cars

### Description:

Créer une nouvelle voiture

### Headers:

```json
  "price": 300,
  "image": "http://..."
}
```

### Response:

```json
{
  "id": 2,
  "name": "Dacia Logan",
  "price": 300,
  "image": "http://..."
}
```

# 🔒 AUTHORIZATION

## Protected routes:

* POST /cars
* PUT /cars/:id
* DELETE /cars/:id
* DELETE /bookings/:id

### Header obligatoire:

```
Authorization: Bearer YOUR_TOKEN
```
